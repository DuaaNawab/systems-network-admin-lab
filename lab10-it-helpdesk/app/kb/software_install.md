# Software installation
1. Only install software from the approved software list on the IT services page.
2. Students cannot install software on lab computers. Request it through the helpdesk and name the course.
3. On a personal laptop, download the installer from the official vendor site and check that the file name matches.
4. Free educational licences are available for some tools. Sign in with your university email to claim them.
5. Never install cracked or pirated software.
