# Wi-Fi connectivity
1. Turn Wi-Fi off and on again, then forget the campus network and reconnect.
2. Select the network named "Campus-WiFi" and sign in with your student ID and portal password.
3. If you changed your password recently, update it on the device as well.
4. Restart the device. If the problem continues, move closer to an access point and test again.
5. If other devices also fail in the same place, report the building and room number to the IT helpdesk.
